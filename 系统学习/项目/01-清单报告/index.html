项目 01：服务器清单报告

日期：2026-11-08

背景：配合第二单元练习容器、文件、JSON、异常与函数。模拟资产数据，不访问网络。

在此目录运行 python inventory_report.py servers.json report.json；Linux 使用 python3。预期报告为：

{"total": 2, "online": 1, "offline": 1, "offline_names": ["db-01"]}

输出文件若存在会覆盖，输入输出不能指向同一文件。失败会显示原因并返回非零；数据校验在打开输出文件之前完成。此入门版没有采用临时文件加原子替换，写入过程中磁盘故障可能留下不完整输出，后续脚本工程单元会补充。

阅读顺序：build_report → main 中文件读写 → 异常分支 → 入口。sys.argv、sys.exit、os.path 的具体作用见第二单元及代码位置，暂不需要掌握整个模块。

待办：按第二单元完成四项练习。来源为本地教学编写，原始知识参考已有下载资料。

验证：WSL Python 实际运行 9 个 CLI 场景通过，包括正常清单、空清单、字段类型错误、重复名称、最外层类型错误、缺失字段、参数不足、输入缺失、输入输出同文件。检查了输出报告与无效数据时原输出保留。尚未模拟磁盘写满等系统故障。
