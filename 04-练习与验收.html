04 快速上手：只做三个任务

更新日期：2026-11-08

背景

根据 GitHub 资料的基础操作与本地示例缩减练习。目标是尽快独立改出功能；以下是待完成任务，不是已实现清单。

任务一：处理数据

运行 structures.py，在服务器列表增加 cache-01，设置为离线。自己写函数返回全部离线名称。

通过标准：包括 db-01 和 cache-01；全部在线时返回空列表；说得清 return 与 print 的差别。

任务二：增加接口

启动 server.py，仿照 /api/servers 新增 GET /api/health，返回 JSON：{"status": "ok"}。

通过标准：浏览器能读取；未知路径仍返回 404；能解释 do_GET 由谁调用、响应为什么编码为字节。

任务三：同时改两端

为 Python 返回的服务器增加 port。浏览器页面和 Node 客户端都显示名称、状态、端口。关闭 Python 后再次请求，核对错误提示。

通过标准：正常时两端都有结果；失败时给出错误而不是一直加载；能解释回调何时执行。

三项完成后再做

POST 提交 → 字段校验 → SQLite 保存，按这个顺序一次加一项。此时可阅读配套资产项目的 真实网站后端 与 前端，不必提前学习所有算法和框架。

来源与待办

来源见 GitHub 筛选记录，任务是针对本仓库重新设计，不是照搬原项目作业。待办：完成三项，并记录一次失败的原因和修复方法。
