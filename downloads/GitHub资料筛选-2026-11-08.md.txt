## 核实事实

- CPython 根据请求方法构造 do_ 开头的方法名并查找、调用；do_GET 不是业务方任意起名。
- Python 容器章节覆盖本地速记选取的容器及操作；learn-python 列表示例包含预期结果核对方式，也包含当前无需学习的内容。
- MDN 的网络请求学习目标使用 fetch。为匹配用户当前基础语法与现有代码，笔记解释同一交互链路，本地示例继续用 XMLHttpRequest；两者 API 不相同。
- Node 文档说明 GET 客户端、响应读取和事件；本地脚本使用普通函数回调，未照搬上游箭头函数或解构。

## 编辑取舍与结论

以下是针对用户的学习建议，不是来源项目的要求：

- 数据结构先学列表、字典、集合与循环，暂缓算法体系。
- 网络先跑通 HTTP GET，暂缓原始 TCP、UDP 和协议栈。
- 前端先学 DOM、事件、回调与 JSON，暂缓框架、构建工具和异步简写。
- 练习收敛为三个：筛选离线机器、新增健康接口、两端显示新字段。
- 已压缩 01—04 笔记并更新 README；已有示例没有改动，无须重新安装依赖。
