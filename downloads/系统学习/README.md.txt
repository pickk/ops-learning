# 系统学习路线：运维脚本与运维平台

更新日期：2026-11-08

## 起点与目标

从变量、条件、循环和函数开始，最终能独立编写巡检脚本、管理资产、开发任务执行平台。完整范围及最终验收见 [十单元建设清单](整套课程建设与验收-2026-11-08.md)。

## 已写好的连续课程

1. [第一单元：Python 编程基础](第一单元-Python编程基础.md)：概念、执行过程、20 个代码块、练习与答案。
2. [第二单元：数据结构与文件处理](第二单元-数据结构与文件处理.md)：容器、文件、JSON、异常；配套清单报告项目。
3. [第三单元：Linux 与运维脚本工程](第三单元-Linux与运维脚本工程.md)：权限、进程、参数、环境、日志、超时、原子写入、定时任务；配套本机巡检 CLI。
4. [第四单元：类、继承与模块组织](第四单元-类继承与模块组织.md)：实例、self、初始化、方法覆盖、组合、模块、测试；配套可替换检查器。
5. [第五单元：网络编程与 HTTP 接口](第五单元-网络编程与HTTP接口.md)：TCP、HTTP、JSON、客户端、服务端、校验、超时与重试边界；配套批量网站巡检和结果接口。

6. [第六单元：数据库与资产管理后端](第六单元-数据库与资产管理后端.md)：SQL、参数绑定、事务、校验、分页；配套持久化资产 API。
7. [第七单元：前端与 Node 交互](第七单元-前端与Node交互.md)：HTML/CSS、JavaScript、DOM、事件、回调、同源；配套真实资产工作台与 Node 客户端。
8. [第八单元：运维任务队列与执行](第八单元-运维任务队列与执行.md)：持久队列、线程/进程、状态机、白名单、事务领取、超时与恢复；配套网页提交真实磁盘/TCP 检查。
9. [第九单元：登录权限与部署](第九单元-登录权限与部署.md)：身份部分已有连续课程和可运行登录平台；继续读[部署备份补充课](第九单元补充-部署备份与恢复.md)，备份恢复与真实进程生命周期已验证，Nginx/TLS 临时实验已通过，系统服务安装未验证。

每课按“读概念 → 手工预测 → 运行 → 改输入 → 独立练习 → 对答案”推进，不用固定每天完成一课。通过练习后再进入下一阶段。

10. [第十单元：综合实战与独立开发](第十单元-综合实战与独立开发.md)：重建路线、完整演练、故障定位、扩展和交付。
